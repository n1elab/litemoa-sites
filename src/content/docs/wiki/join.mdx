## 統合版(BE)
スマホ（iOS/Android）、タブレット、Switch、PS4/5、Xboxなどでプレイされている方はこちらです。<br />
参加方法は「サーバー追加」と「フレンド申請」の2通りあります。


### 1.フレンド申請で参加
SwitchやPS4/5など、直接サーバーアドレスを入力できない場合フレンド申請を送ることで「フレンド」タブから参加できます。
| 項目 | 設定内容 |
| :--- | :--- |
| **ゲーマータグ** | `litemoa1` |

### 2.サーバー追加で参加
Windows・スマホ・タブレットでプレイしている方は以下の方法でご参加ください。<br />
「サーバー」タブから「サーバーを追加」を選択し、以下の情報を入力してください。
| 項目 | 設定内容 |
| :--- | :--- |
| **アドレス** | `liteplay.n1e.net` |
| **ポート** | `19132` |

## 🛠️ 接続できないときは？

もしサーバーに入れない場合は、以下の点を確認してください。

1.  **アドレス・ポートの入力ミス**: サーバーアドレスやポート番号が半角英数字で正しく入力されているか。
2.  **Microsoftアカウント**: BE版の場合、サインインしている必要があります。
3.  **インターネット接続**: Wi-Fiやモバイルデータ通信が安定しているか。
4.  **メンテナンス**: 公式Discordなどでメンテナンス情報が出ていないか確認してください。
