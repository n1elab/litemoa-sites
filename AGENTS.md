# AGENTS.md

## Project Overview

This repository contains the official website for Litemoa Server, a Minecraft community server.

The project uses Astro. Refer to `README.md`, `package.json`, and existing source files for further details.

## Development Guidelines

- Inspect relevant code and documentation before making changes.
- Follow existing project conventions and directory structure.
- Prefer simple, maintainable solutions.
- Keep changes focused on the requested task.
- Avoid unrelated refactoring or introducing unnecessary dependencies.
- Preserve existing functionality unless changes are explicitly requested.

## Code Style

- Follow the existing formatting and naming conventions.
- Prefer reusable components for repeated UI elements.
- Use semantic HTML where appropriate.
- Maintain accessibility and responsive layouts.
- Avoid adding new frameworks or libraries without a clear reason.

## Design Guidelines

- Preserve the project's established visual identity.
- Keep the website usable and understandable for visitors.
- Do not introduce major visual changes without approval.
- Ensure that new components remain consistent with existing components.

## Validation

- Check `package.json` for available scripts.
- Run the relevant checks and build commands when possible.
- Report any checks that could not be completed.
- Do not claim that changes have been tested unless they actually have been.

## Communication

- Explain significant implementation decisions.
- State assumptions when requirements are ambiguous.
- Ask for clarification before making consequential decisions.
